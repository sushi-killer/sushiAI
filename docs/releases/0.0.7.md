> Extension API: 1

## Extensions: sushiAI is now plugin-extensible

- A new extension contract lets a declarative `manifest.json` add its own
  navigation entries, panes, toolbar actions and commands to the app - no
  executable code ships with an extension, only UI and data description.
- Extensions get their own persisted state, scoped per pane, per project, or
  globally, and a singleton surface (like a settings page) reveals its
  existing pane instead of opening a duplicate.
- The extension manifest's compatibility version (`apiVersion`) is tracked
  independently of sushiAI's own release version, so a future third-party
  extension author has a stable contract to build against even as the app
  keeps shipping.
- The previous ad-hoc Tasks/Links demo data has been replaced by a Probe
  fixture built specifically to exercise everything the contract allows.

## Verification

The release candidate passes the full automated suite (`npm run ci`),
including the extension-contract tests against the new Probe fixture and the
production renderer build. The harness and release pipeline were reviewed
twice against the actual code rather than taken on trust, catching four real
bugs - a release publishing before its installer uploads, an unpinned tag, a
stale hardcoded dmg title, and `release.mjs` mutating files before creating
its branch - all fixed in this release.

## Install or update

Download **sushiAI-0.0.7-arm64.dmg** and drag **sushiAI** into
**Applications**, or use **Settings → Software updates → Install and
restart**. Requires Apple Silicon and macOS 13 or later. Save edits before
restarting: local terminals stop; Herdr sessions keep running.

The build is ad-hoc signed, not Apple-notarized. See the
[installation guide](https://github.com/sushi-killer/sushiAI/blob/v0.0.7/docs/INSTALL.md).
To verify the DMG, download `SHA256SUMS.txt` beside it and run
`shasum -a 256 -c SHA256SUMS.txt`.
