## Skills inventory and editor

- Scan local Codex, Claude and other agent skill roots with a persistent cache, so revisiting the Skills section does not redraw the catalog from scratch.
- Group skills by owner and harness, with filters for all, recent, changed, duplicates, unused, stale, disabled and external skills.
- Show last-use signals, call counts when local events provide them, update dates, duplicate copies and cleanup recommendations.
- Edit `SKILL.md` in a fixed VS Code-style editor tab with line numbers, wrapping, fullscreen mode, draft diff stats and local save conflict protection.
- Highlight Markdown plus YAML frontmatter, including `name`, `description`, scalar values and delimiters.
- Enable, disable or delete local skills and disable, enable or uninstall provider plugins directly from the catalog, with safeguards for system skills and unsaved edits.

## Verification

Added regression coverage for catalog discovery, cache behavior, provider configuration changes, duplicate and disabled states, editor syntax highlighting and YAML frontmatter parsing.

## Install or update

Download **sushiAI-0.0.5-arm64.dmg** and drag **sushiAI** into **Applications**, or use **Settings → Software updates → Install and restart**. Requires Apple Silicon and macOS 13 or later. Save edits before restarting: local terminals stop; Herdr sessions keep running.

The build is ad-hoc signed, not Apple-notarized. See the [installation guide](https://github.com/sushi-killer/sushiAI/blob/v0.0.5/docs/INSTALL.md). To verify the DMG, download `SHA256SUMS.txt` beside it and run `shasum -a 256 -c SHA256SUMS.txt`.
