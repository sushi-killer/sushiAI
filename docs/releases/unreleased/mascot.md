## The desktop mascot

- Orchestrator task notices appear as a sushi mascot in the corner of the screen when a task needs your input, is done ("Feature done: <title>" with its cost, review result and landing) or failed.
- Answer a question right in the bubble (pick an option with 1-9), land a finished task, rerun a failed one or open it in the Orchestrator panel. A newer question from the same task replaces the older notice.
- An optional global shortcut, ⌥Space, folds the notices into a small pill and back from any app. It is off by default (Settings > General) so it does not clash with launchers; if another app holds ⌥Space, the setting says so. The mascot also folds itself while a fullscreen app or a slideshow runs.
- Its mood follows the work: it waves when a task needs you, watches while you type, cheers when work is done and worries when it fails. With reduced motion on it keeps still.
- Turn it off in Settings > General > Background (**Desktop mascot**) to get native notifications instead.
