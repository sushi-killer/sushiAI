# orchd settings

Every orchestrator setting lives in one settings object, read and written as a
whole (`settings.get` / `settings.set`). Change it in **Settings →
Orchestration**. A key with no control there is edited under **Advanced — all
settings as JSON**, the same object saved through the same call. The source of
truth is the `Settings` struct in `orchd/src/model.rs`; the defaults below are
the ones a fresh install gets.

Settings hold no secrets. Model-provider keys stay in **Settings → Models**.

| Key                          | Type                                                                                 | Default                                                        | What it does                                                                                                                                                                | Where to change it                               |
| ---------------------------- | ------------------------------------------------------------------------------------ | -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| `routes`                     | list of `{id, label, harness, model?, effort?, profileId?, strength?}`               | `claude-sonnet`, `claude-opus`, `codex`                        | The model routes a task can run on. `strength` (1 to 3) orders routes for review.                                                                                           | Models & routes; route strength under Advanced   |
| `tiers`                      | `{mechanical, standard, hard}` route ids                                             | `codex`, `claude-sonnet`, `claude-opus`                        | The route each task tier implements on.                                                                                                                                     | Models & routes                                  |
| `review`                     | route id, `""` or `"auto"`                                                           | `"auto"`                                                       | Who reviews a passed attempt. `""` turns review off; `"auto"` picks the cheapest route never weaker than the implementer.                                                   | Models & routes                                  |
| `planner`                    | route id or `""`                                                                     | `claude-opus`                                                  | Route that drafts a plan from a one-sentence request. `""` turns drafting off.                                                                                              | Models & routes                                  |
| `briefCheckRoute`            | route id or `""`                                                                     | `codex`                                                        | Read-only run that checks a brief for contradictions before the first attempt. `""` turns the check off.                                                                    | Checks and worktrees: Cheap checks route         |
| `orchestrator`               | route id or `""`                                                                     | `""` (the standard tier's route)                               | Route of the orchestrator chat and, with `autoAnswer`, its answers to stuck questions.                                                                                      | Models & routes                                  |
| `autoAnswer`                 | boolean                                                                              | `false`                                                        | The orchestrator answers a stuck agent's question before it reaches you, and logs what it chose.                                                                            | Autonomy                                         |
| `answerPolicy`               | boolean                                                                              | `true`                                                         | Routine questions are answered by rules and a cheap judge (at most three per task) and recorded as assumptions. `false` asks you every time.                                | Advanced JSON                                    |
| `sandbox`                    | `"native"` or `"host"`                                                               | `"native"`                                                     | Whether agents run in the harness sandbox or directly on the host.                                                                                                          | Safety & limits                                  |
| `allowedDomains`             | list of strings                                                                      | `["*"]`                                                        | Claude's per-domain network allowlist.                                                                                                                                      | Safety & limits                                  |
| `codexNetwork`               | boolean                                                                              | `false`                                                        | Codex has no per-domain filter: network is all or nothing.                                                                                                                  | Safety & limits                                  |
| `protectedPaths`             | list of strings                                                                      | `[]`                                                           | Paths an attempt may not change.                                                                                                                                            | Safety & limits                                  |
| `maxAttempts`                | integer                                                                              | `4`                                                            | Attempts before a task comes to you.                                                                                                                                        | Safety & limits                                  |
| `parallel`                   | integer                                                                              | `2`                                                            | Task loops running at once, across every repo.                                                                                                                              | Safety & limits                                  |
| `childParallel`              | integer                                                                              | `3`                                                            | Subtasks of one parent running at once.                                                                                                                                     | Safety & limits                                  |
| `dailyBudgetUsd`             | number                                                                               | `0` (off)                                                      | Dollars a UTC day may spend before orchd asks instead of starting more work.                                                                                                | Budget                                           |
| `autopilot`                  | boolean                                                                              | `false`                                                        | Start ready `next`-bucket backlog tasks by themselves while fewer than `parallel` loops are live.                                                                           | Advanced JSON                                    |
| `experiments`                | object of flags (see below)                                                          | `loopDetect: true`, `land: true`, the rest off or 0            | Flags every new task starts with; `task.create` can override them per task.                                                                                                 | Budget, Land finished work, Advanced experiments |
| `prices`                     | model id to `{input, cachedInput, output, cacheWrite?}` (dollars per million tokens) | Codex and Claude models shipped with orchd                     | Prices for harnesses that report tokens but no cost.                                                                                                                        | Advanced JSON                                    |
| `workBuckets`                | `{process: [...], evidence: [...]}`                                                  | both empty                                                     | Repo-specific tool-input fragments that count as process or evidence work in `orchd ab`.                                                                                    | Advanced JSON                                    |
| `evolution.minTasks`         | integer                                                                              | `3`                                                            | Earlier tasks a repo needs before its baselines mean anything.                                                                                                              | Advanced JSON                                    |
| `evolution.minWastedCalls`   | integer                                                                              | `20`                                                           | Tool calls a cluster of signals must have wasted to justify a proposal.                                                                                                     | Advanced JSON                                    |
| `evolution.minWastedUsd`     | number                                                                               | `1.0`                                                          | Dollars a cluster must have wasted to justify a proposal.                                                                                                                   | Advanced JSON                                    |
| `evolution.maxProposals`     | integer                                                                              | `3`                                                            | Proposals one round may make.                                                                                                                                               | Advanced JSON                                    |
| `evolution.proposerRoute`    | route id or `""`                                                                     | `""` (the hard tier's route)                                   | Route that writes proposals.                                                                                                                                                | Advanced JSON                                    |
| `evolution.revertAfterTasks` | integer                                                                              | `10`                                                           | Tasks after which an accepted change is judged and possibly reverted.                                                                                                       | Advanced JSON                                    |
| `worktreeRoot`               | path                                                                                 | `.sushiai/worktrees`                                           | Where new task worktrees go; a relative path is resolved against the repo root. Existing tasks keep their path.                                                             | Checks and worktrees: Worktree folder            |
| `verifyTimeoutSecs`          | integer (seconds)                                                                    | `1200` (an orchd without the key uses its built-in 20 minutes) | How long one verify command may run before it is stopped.                                                                                                                   | Checks and worktrees: Verify timeout             |
| `landOnDefault`              | boolean                                                                              | `false`                                                        | Tasks may move a repo's default branch. Off: such a landing is refused and the task stays done on its own branch.                                                           | Advanced JSON                                    |
| `landOnDefaultRepos`         | repo path to boolean                                                                 | `{}`                                                           | Per repo, overrides `landOnDefault`.                                                                                                                                        | Safety & limits                                  |
| `afterLand`                  | list of `{repo, run}`                                                                | `[]`                                                           | Shell command `run` executed in the main checkout `repo` after a task lands there, for example to rebuild a binary.                                                         | Advanced JSON                                    |
| `scopedChecks`               | list of `{repo?, command, paths}`                                                    | `[]`                                                           | A command that runs only when the task's diff touches one of its `paths` globs; `command` is a glob over the whole command string. Without `repo` it applies to every repo. | Advanced JSON                                    |
| `chatTools`                  | list of connected MCP tools                                                          | `[]`                                                           | Servers the orchestrator chat may use, each toggled on or off. Servers are definitions or references, never secrets.                                                        | Connected tools                                  |

## `experiments` flags

| Flag                                                                                      | Default | What it does                                                                                         |
| ----------------------------------------------------------------------------------------- | ------- | ---------------------------------------------------------------------------------------------------- |
| `stallTimeoutSecs`                                                                        | `0`     | Stop an attempt whose harness prints nothing for this long; 0 is off.                                |
| `reviewEvidence`                                                                          | `false` | The reviewer gets saved screenshots and longer verify output.                                        |
| `advisor`                                                                                 | `false` | After a failed attempt, one read-only call diagnoses it for the next attempt.                        |
| `loopDetect`                                                                              | `true`  | Stop an attempt that repeats itself.                                                                 |
| `land`                                                                                    | `true`  | A passed task lands on its base branch by itself (never on the default branch unless allowed above). |
| `maxCostUsd`, `maxAttemptCostUsd`                                                         | `0`     | Dollar caps per task and per attempt; 0 is none.                                                     |
| `plannerRoute`, `tierRoutes`, `batchQuestions`, `groundedChecks`, `bestOf`, `bestOfRoute` | off     | Experiment arms; see `Variant` in `orchd/src/model.rs` for each.                                     |

Only settings reachable through the app are listed with a control. A key
missing from the list above but present in `orchd/src/model.rs` is still
editable in the Advanced JSON, which shows the whole object as the daemon
returned it.
