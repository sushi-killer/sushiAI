Upstream merged work is not claimed as a new implementation here.

## Current large files and actual removals

No current Rust file has at least 1,000 total physical lines. No mixed/runtime god-file exception is registered.

The actual removed runtime paths are the ERROR_STREAK heuristic and its text normalization/state, and the report-only LLM invocation after a time budget. Repeated exact calls/edits, stall, permissions, cancellation, cost and attempt gates remain. Task-owned criteria, authority, amendment and baseline operations replace duplicate mutation bodies. Common native settlement records usage once. Shared advisor request construction removes its duplicate request body. PR, verification, process, serde, AB and evolution code was otherwise relocated or decomposed with its behavior retained. Test/helper relocation is reported only in its own category.

Seven planning snapshots dropped one duplicated measurement paragraph each (513 bytes including the separator); every planning builder still emits the instruction once. Three PR snapshots add the code-owned Validation instructions. This is prompt fixture deduplication, not removal of a check or production gate.

Compiled task, planning and delivery YAML drives closed typed operations. No new workspace crate, actor, revision, generation, provider protocol, storage migration or general workflow language is included. The twelve research recommendations and their later stages remain in [goal status](orchd-simplify-status.md).
