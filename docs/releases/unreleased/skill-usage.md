## Skill usage from your sessions

- The Skills screen now counts how often each skill ran in the last 90 days from your Claude Code and Codex session transcripts, and shows the last use per skill. The first run indexes your history in the background and can take a few minutes; the screen updates when it is done.
- Each skill shows the size of its description in tokens, and the header shows how much of your active skills' descriptions no session used in 90 days. The Unused filter lists the largest first.
