## Inbox, notifications that follow up, and a worktree per session

- The "Sessions" item in the sidebar is now **Inbox**, and it leads the list, ahead of Routines and Dashboard: a page that puts every agent on every host in one attention queue. Groups run from the most urgent: needs input, finished but not yet seen, working, idle, shells. Each row shows its project and host. Jump opens the session, and "Clean up" selects idle shells and agents you have already seen so they can be ended together. The sidebar item shows how many things are waiting.
- sushiAI sends a macOS notification when an agent needs your input or finishes. Clicking the notification opens that session. If an agent is still waiting, reminders follow at 5, 10 and 20 minutes. The Dock badge and the menu bar icon show how many things are waiting.
- The menu bar icon now says what is going on without being opened: a plain mark when nothing needs you, a ring while agents are running, a filled dot when something is waiting - with the count beside it. Clicking the icon opens its menu; **Open** brings the window back.
- Closing the window no longer quits sushiAI: it keeps running in the menu bar, so notifications and reminders keep coming. Quit from the menu bar icon or with ⌘Q. Both behaviours can be switched off in Settings → General → Background.
- Adding a terminal or an agent can launch it in a new git worktree on its own branch, so parallel agents never share a working tree. It works for Herdr sessions on this Mac or an SSH host, and for local sessions on this Mac, where sushiAI creates the worktree next to the repository. The new worktree joins the project's row in the sidebar.
- The bell now lists app updates and agent activity; agents waiting for input live in Inbox.
