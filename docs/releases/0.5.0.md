> Extension API: 1

## Artifacts

- An agent can now show you what it wrote in a Preview half of its own pane. Drag the divider to resize it, hide it with ×, and bring it back from the pane header (a dot shows the file changed). Full screen shows both halves; closing the agent closes its Preview. Your focus stays in the terminal. Preview shows Markdown documents and plans, any HTML file (reveal.js decks, Mermaid diagrams, reports), SVG, images and PDF, and updates as the agent edits the file. It works on SSH hosts too.
- Select text, or point at an element of a deck or diagram, to leave a comment. **Send** delivers all your comments to the agent as one message, marked as owner feedback from the Preview. Unsent comments survive hiding the Preview.
- Edit a Markdown document in place with the pencil, then **Save** (⌘S). The agent is told you changed the file. Copy puts the document's Markdown on the clipboard.
- A plan has a **Start task** button next to its tags. You pick Claude Code or Codex, which opens a new pane in a new worktree and starts with `/goal <plan>`, or the orchestrator. The same spot then shows the run: **Open** goes to the running agent, and an ended session or a failed start offers **Restart** or **Retry**. Plans show whether the agent checked them for contradictions ("Verified").
- sushiAI installs the `sushiai-artifacts` skill globally for Claude Code, Codex and other harnesses that read `~/.agents/skills`, on your Mac and on every SSH host, so any agent started from sushiAI knows how to open a Preview. You can turn Artifacts off in Extensions.
- Extensions: a built-in extension surface can now open as the companion half of an agent pane.

## Workspace

- Closing the final panel now leaves its project in the Workspace list, including after restarting the app. The project remains until it is closed from Project Settings.

## Orchestrator

- Updating the orchestrator on an SSH host no longer fails with "did not stop within 10 s" when the connection is slow to come up: sushiAI now retries until the running orchestrator receives the shutdown, instead of giving up after one early attempt.
