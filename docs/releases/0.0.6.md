## Git history and workspace controls

- Browse a compact, gap-free commit graph across all refs or one selected branch.
- Selecting a branch is read-only and never checks out or changes the worktree.
- Local branches, branches tracking `origin`, and origin-only branches are identified in the picker.
- Inspect commit files and diffs, including merge commits and root commits.
- Persist the selected workspace layout and panel mode across app restarts.
- Manage custom model providers and Claude Code MCP/plugin settings from the workspace UI.

The release candidate passes the full automated suite and production renderer build. The Git history UI was also checked manually in the desktop dev build after a clean restart.

## Install or update

Download **sushiAI-0.0.6-arm64.dmg** and drag **sushiAI** into **Applications**, or use **Settings → Software updates → Install and restart**. Requires Apple Silicon and macOS 13 or later. Save edits before restarting: local terminals stop; Herdr sessions keep running.

The build is ad-hoc signed, not Apple-notarized. See the [installation guide](https://github.com/sushi-killer/sushiAI/blob/v0.0.6/docs/INSTALL.md). To verify the DMG, download `SHA256SUMS.txt` beside it and run `shasum -a 256 -c SHA256SUMS.txt`.
