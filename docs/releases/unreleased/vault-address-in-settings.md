## Vault address in Settings

- The Vault address now lives in Settings, Vault tab, next to the token. A project's Vault section keeps only the mount and the paths. On the first start, sushiAI moves the saved project addresses into the setting. If projects used different addresses, it keeps the most used one, shows one notice that names the others, and keeps that line in Settings, Vault tab until you dismiss it.
- The variable names that come from Vault now show in the project's Variables list in the Environment tab, with a Vault mark. They show automatically; the values never show. When the read fails, the list shows the reason, for example "Vault: unreachable". The Check button is gone.
