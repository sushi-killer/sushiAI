## Your workspace comes back after a restart

- sushiAI now keeps your whole workspace in one file in its data folder (`workspace-state.json`) instead of the browser storage inside the app. The file is written a moment after every change and once more when the window closes, so quitting, killing the app or restarting it brings back the same layout: panes and their split sizes, the selected and maximized pane, tabs or split view, the open page (Dashboard, Skills, an extension page) and the Code, Agent or Chat mode.
- Panes remember what they were showing. A Files pane reopens in the same folder with the same file open, the Orchestrator reopens on the task you were reading, and the Agent tabs, the open Agent conversation and the open Chat thread come back too. Merged-project layouts are kept in the same file. Unsent drafts are still never saved.
- A Herdr session that ended while sushiAI was closed no longer vanishes from its layout slot. The pane stays where it was and says "Session ended" with a **Reopen** button, which starts a fresh session in the workspace's folder (and relaunches the agent for an agent pane). A workspace Herdr no longer lists stays in the sidebar the same way, and Reopen creates it again.
- The first start after updating moves your previous layout, Agent tabs and focus into the new file once and removes the old browser-storage entries.
