## Inbox replaces Sessions

- **Inbox** leads the sidebar, ahead of Routines and Dashboard, and puts every agent on every host in one attention queue, with or without the orchestrator. Groups run from the most urgent: needs input, finished but not yet seen, working, idle, shells. Each row shows its project and host, and the sidebar item shows how many things are waiting.
- Claude Code and Codex questions can be answered from the Inbox. Orchestrator tasks that wait on you, failed, wait to land or stopped on their own appear under **Orchestrator**; clicking a row opens the task.
- Rows have a preview and keyboard triage. **Clean up** selects idle shells and agents you have already seen and shows what it will close before it does.
- The bell now lists app updates and agent activity; agents waiting for input live in the Inbox.

## Notifications, Dock badge and menu bar

- sushiAI sends a macOS notification when an agent needs your input or finishes; clicking it opens that session. If you do not answer, reminders follow at 5, 10 and 20 minutes.
- The Dock badge and the menu bar icon show how many things are waiting. The menu bar icon reads at a glance: a plain mark when nothing needs you, a ring while agents run, a filled dot with the count when something waits. **Open** in its menu brings the window back.
- Closing the window no longer quits sushiAI: it stays in the menu bar so notifications and reminders keep coming. Quit from the menu bar icon or with ⌘Q.
- Both behaviours can be switched off in Settings > General > Background.
