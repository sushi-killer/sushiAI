## Session names in Remote

- A new agent session is named after the first line of its first prompt, cut to 40 characters at a word boundary, instead of the agent product name. Sessions in Remote no longer all read "Claude Code". The name is shown on all your devices, so a secret typed as the first line would show there too; rename the session to change it. A session you renamed keeps its name. Until the first prompt, the phone shows the folder name and the desktop tab shows the agent name. Agents without hooks (Gemini, Cursor Agent) show their own name.
