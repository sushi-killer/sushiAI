## Terminal selection, copying and keyboard controls

- Select and copy text while Claude is updating: Herdr rendering pauses during selection and resumes when you continue interacting.
- Cleaner copied prose: remove terminal wrapping, trailing/repeated spaces and encoded indentation while preserving code, lists, tables and paragraph breaks.
- macOS editing shortcuts: Command+Left/Right for line navigation, Command+Backspace to delete to the start, and Option+Left/Right/Backspace for word editing.
- Shift+Enter is sent as a distinct key sequence for compatible agent CLIs.

## Scrolling and terminal rendering

- Default scrolling is 30% faster, with Option acceleration.
- Claude wheel input targets the application, including during redraws that temporarily disable mouse reporting. Repeated process lookups no longer block steady scrolling.
- Jump to bottom clicks resume a screen paused by text selection.
- Resizing waits for pending output and the settled panel size, preventing long text from becoming corrupted during layout changes.
- Remove the local scrollbar that could navigate stale Herdr frames.
- UTF-8 defaults for local shells and newly created Herdr workspaces/panes fix broken Cyrillic input. Stream decoding preserves characters split across frames.
- Bundled Nerd Font symbols display shell and file-list icons without a separate font installation.

## Harness attachments and error handling

- Paste or drop images/files into active agent harnesses, including local Herdr and SSH sessions. Ordinary shell sessions reject attachments, including after leaving an agent.
- Files are transferred to the host running the session; paths are quoted and inserted using terminal paste handling.
- Ordered uploads, a drop-target highlight, transfer status and focus restoration. Up to eight files per operation, 20 MB per file.
- File drops no longer trigger panel rearrangement.
- Dismiss attachment errors without disconnecting the running terminal; reconnect remains available for disconnected sessions.
- Unique attachment filenames and private file permissions.

## Verification

Added regression coverage for selection/copying, keyboard shortcuts, resizing, wheel routing, delayed process lookups, Jump to bottom, Unicode, font loading, local/remote attachment handling and shell rejection. Includes real zsh and Herdr integration checks.

## Install or update

Download **sushiAI-0.0.4-arm64.dmg** and drag **sushiAI** into **Applications**, or use **Settings → Software updates → Install and restart**. Requires Apple Silicon and macOS 13 or later. Save edits before restarting: local terminals stop; Herdr sessions keep running.

Existing Herdr shells retain their environment. If an older shell still has broken Cyrillic input, open a new terminal panel or run `export LANG=en_US.UTF-8 LC_CTYPE=en_US.UTF-8 LC_ALL=en_US.UTF-8` in that shell.

The build is ad-hoc signed, not Apple-notarized. See the [installation guide](https://github.com/sushi-killer/sushiAI/blob/v0.0.4/docs/INSTALL.md). To verify the DMG, download `SHA256SUMS.txt` beside it and run `shasum -a 256 -c SHA256SUMS.txt`.
