## A base carry conflict is an ordinary step

- When orchd carries a task onto a moved base and the carry conflicts, the task's own agent resolves it on the task's own route, resuming its session when it can. The brief names the conflicted files and says to regenerate anything generated from the old base. Verify, review and the pull request then run as usual.
- The cheap conflict-only route and the 30-minute "Retry later" timer are gone; a step that keeps failing goes through the normal failure ladder.
